# Screenshots de Volksureste E-commerce

Coloca aquí las capturas de pantalla del proyecto Volksureste.

## Sugerencias de screenshots:

1. **home.jpg** - Página principal del e-commerce
2. **catalog.jpg** - Vista del catálogo de productos
3. **product-detail.jpg** - Página de detalle de producto
4. **cart.jpg** - Carrito de compras
5. **checkout.jpg** - Proceso de checkout
6. **payment.jpg** - Pantalla de selección de pago
7. **admin-dashboard.jpg** - Dashboard del panel administrativo
8. **admin-inventory.jpg** - Gestión de inventario multi-sucursal
9. **pos-system.jpg** - Sistema POS
10. **user-panel.jpg** - Panel de usuario con órdenes

## Especificaciones:
- Formato: JPG o PNG
- Tamaño recomendado: 1920x1080px o 1280x720px
- Peso: < 500KB por imagen (optimizar)
- Nombres descriptivos en inglés (sin espacios)

## Cómo agregar las imágenes al proyecto:

Una vez que coloques las imágenes aquí, actualiza el array `images` en el proyecto 'volksureste' en el archivo `script.js`:

```javascript
images: [
    'images/volksureste/home.jpg',
    'images/volksureste/catalog.jpg',
    'images/volksureste/product-detail.jpg',
    'images/volksureste/cart.jpg',
    'images/volksureste/checkout.jpg',
    'images/volksureste/payment.jpg',
    'images/volksureste/admin-dashboard.jpg',
    'images/volksureste/admin-inventory.jpg',
    'images/volksureste/pos-system.jpg',
    'images/volksureste/user-panel.jpg'
],
```
