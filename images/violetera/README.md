# Capturas de Pantalla - Sistema POS Violetera

Esta carpeta contiene las capturas de pantalla del Sistema POS para Restaurantes Violetera.

## Capturas Requeridas

Por favor, agrega las siguientes capturas de pantalla con los nombres exactos:

1. **login.png** - Pantalla de inicio de sesión del sistema
2. **dashboard.png** - Dashboard principal con métricas y gráficos
3. **comandera-mesas.png** - Vista de la comandera con asignación de mesas
4. **comandera-orden.png** - Pantalla de creación/edición de órdenes
5. **cocina.png** - Panel de cocina con listado de comandas
6. **caja-apertura.png** - Módulo de apertura de caja/turno
7. **caja-corte.png** - Pantalla de corte de caja con reportes
8. **admin-productos.png** - Gestión de catálogo de productos
9. **admin-reportes.png** - Pantalla de reportes y analíticas
10. **admin-usuarios.png** - Gestión de usuarios y roles

## Especificaciones de las Imágenes

- **Formato:** PNG o JPG
- **Resolución recomendada:** Mínimo 1280x720px
- **Peso máximo:** 500KB por imagen (optimizar para web)
- **Proporción:** 16:9 o similar para mejor visualización

## Notas

- Las imágenes se mostrarán en el modal de detalles del proyecto
- Se pueden hacer clic para ver en pantalla completa
- Asegúrate de ocultar información sensible (nombres reales, datos personales, etc.)
- Usa datos de prueba o difuminados si es necesario

## Capturas Opcionales Adicionales

Si deseas agregar más capturas, puedes:
1. Guardarlas en esta carpeta con nombres descriptivos
2. Actualizar el array `images` en `script.js` dentro del objeto `violetera`

Ejemplo:
```javascript
images: [
    'images/violetera/login.png',
    'images/violetera/dashboard.png',
    // ... capturas existentes
    'images/violetera/nueva-captura.png'  // Agregar aquí
]
```
