- **Formato:** PNG o JPG

## Áreas Importantes a Capturar

### cPanel
- Dashboard con estadísticas de uso (disco, ancho de banda, CPU)
- Lista de dominios y subdominios
- Gestión de cuentas de correo
- Administrador de archivos
- Softaculous o instalador de aplicaciones

### WHM (Web Host Manager)
- Lista de cuentas de hosting
- Configuración del servidor
- Gestión de paquetes de hosting
- Resumen de recursos del servidor

### Gestión de Dominios
- Panel de registrador de dominios
- Configuración de DNS (registros A, CNAME, MX, TXT)
- Redirecciones y apuntadores
- Estado de dominios (activos, por renovar)

### Correos Corporativos
- Webmail (Roundcube o similar)
- Configuración de cuentas
- Filtros antispam
- Forwarders y autoresponders

### Certificados SSL
- Instalación de Let's Encrypt
- Lista de certificados instalados
- Renovación automática configurada
- Estado de certificados (válidos, por vencer)

### Monitoreo
- Gráficas de uso de CPU y RAM
- Estadísticas de ancho de banda
- Uptime del servidor
- Alertas y notificaciones

### Backups
- Panel de JetBackup o similar
- Calendarios de backups automatizados
- Lista de backups disponibles
- Opciones de restauración

## Notas de Seguridad

⚠️ **IMPORTANTE: Proteger información sensible**

- Ocultar nombres de dominio reales de clientes
- Difuminar direcciones IP públicas
- No mostrar usuarios y contraseñas
- Ocultar rutas completas del servidor
- Difuminar nombres de bases de datos
- No mostrar claves API o tokens
- Usar datos de ejemplo o servidor de prueba
- Ocultar información de correos reales
